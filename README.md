# ORBIT · 모임 데이터 둘러보기

휴대폰에서 직접 조작하는 3D 모임 지도와 세 가지 연구 그래프입니다.

**공개 주소:** https://tlparche.github.io/orbit-mobile/

- 3D 모임 지도: 회전·확대, 행사 상세, 참여 조건, 행사 목록
- 월별 행사 수: 월을 선택해 해당 행사 탐색
- 대화 주제 비중: 기록별 항목 비율과 SMCC 강조
- 답변 표현의 유사성: 동일한 축의 모임별 분포, 기록 선택, 구간별 비율

로그인·설치·실시간 서버·방문자 추적 없이 실행합니다. 기존 발표와 별도 앱이며 영상·발표·오프라인 ZIP을 포함하지 않습니다.

모든 화면은 기존 ORBIT 웹의 우주 배경·청록 포인트·패널·버튼·차트 색상과 무늬를 사용합니다. 지도는 기존 점·선 셰이더를 그대로 재사용하며 자동 움직임 없이 조작할 때만 렌더링합니다. 모바일에서 큰 터치 영역과 세로 배치를 유지합니다. `src/legacy-theme.css`와 `src/legacy-shaders.mjs`가 원본 디자인의 연결 지점입니다.

## 개발

Node.js 24, Python 3.13을 사용합니다.

```sh
npm ci
python -m pip install -r scripts/requirements-web-assets.txt
python scripts/prepare_web_assets.py
npm test
npm run build
npm run check
npm run serve
```

로컬 주소는 `http://127.0.0.1:8772/orbit-mobile/`입니다. 프로젝트 하위 경로를 포함해 실행하므로 GitHub Pages와 같은 상대 경로로 검수할 수 있습니다.

이미지 240개의 고정 CDN 주소·해시는 `scripts/web_assets.json`에 있습니다. 원본과 360px 미리보기를 빌드 때 준비하며, 바이트가 달라지면 중단합니다. 바이너리는 Git에 넣지 않습니다. 다운로드 캐시가 있으면 `python scripts/prepare_web_assets.py --offline --cache-dir <cache-folder>`로 재사용할 수 있습니다. `--check`는 기존 결과만 검사합니다.

## 데이터

`public/data/`는 기존 연구 결과의 공개용 투영입니다. 인터뷰 원문·답변 추적 ID·개인정보·로컬 경로는 포함하지 않습니다. 일반 빌드는 원자료나 분석 환경을 필요로 하지 않습니다.

- 지도: 241개 행사, 278개 연결. 기존 300회 force 배치의 고정 좌표.
- 월별: 2025년 12월~2026년 11월, 239개. 날짜 미확인 2개 제외. 2026.10.26 스냅샷 당시 예정 행사 1개 포함.
- 조건: 본문 있는 240개 기준. 조건 미선택 시 본문 없는 1개까지 포함한 241개. 그룹당 하나를 선택하며 그룹 간 교집합.
- 차트: 7개 익명 대화 기록의 비율·히스토그램. 원본 수치와 공통 축 유지.
- 선은 모집 문구·이미지의 유사성입니다. 실제 교류나 인기도를 뜻하지 않습니다.

새 스냅샷을 반영할 때만 로컬에서 `node scripts/import-snapshot.mjs <기존-작업폴더> <기존-웹출력폴더>`를 실행합니다. 이 스크립트는 허용한 필드만 복사하고 기존 배치 계산을 재사용합니다. 모델·수집·분석을 실행하지 않습니다.

## 배포

GitHub Pages의 Source를 **GitHub Actions**로 설정합니다. `codex/mobile-explorer` 또는 `main`에 push하면 테스트·빌드·에셋 검증 후 `dist/`만 배포합니다. QR은 이 저장소 이름과 공개 주소에 연결되므로 저장소 이름을 바꾸면 다시 생성해야 합니다.

주요 주소: `#/map`, `#/monthly`, `#/topics`, `#/similarity`. 상세 패널은 query에 기록되어 브라우저 뒤로 가기로 닫을 수 있습니다. 세션 안에서 화면별 선택과 스크롤을 유지하며 새로고침하면 필터를 초기화합니다.

## 접근성과 오류 대응

48px 이상 버튼, 기본 18px 글씨, 16px 이상 보조 라벨, 200% 글자 확대, 키보드 포커스와 다이얼로그를 지원합니다. 지도는 자동으로 움직이지 않으며 탭 숨김·다른 화면·상세 열기에서 렌더링을 멈춥니다. WebGL 오류 시 행사 목록·조건을 계속 사용할 수 있습니다. 불러오기 실패에는 재시도 버튼이 있습니다.
